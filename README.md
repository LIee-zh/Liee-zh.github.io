# 田曦薇 · 个人资料站

一个中英双语、共六页的静态个人资料站，无表单，用来做课程作业示例。

## 中文

- 首页：https://liee-zh.github.io/
- 作品：https://liee-zh.github.io/works.html
- 资料：https://liee-zh.github.io/profile.html

## English

- Home: https://liee-zh.github.io/index-en.html
- Works: https://liee-zh.github.io/works-en.html
- Profile: https://liee-zh.github.io/profile-en.html

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` `works.html` `profile.html` | 中文三页：简介、年表、履历 |
| `index-en.html` `works-en.html` `profile-en.html` | 英文三页，与中文内容对应 |
| `styles.css` | 全站共用样式（白底、单一强调色、细线表格） |
| `xiwei-1.jpg` `xiwei-2.jpg` `xiwei-3.jpg` | 三张写真，来自公开写真 |

## 说明

资料整理自公开报道；本站为课程作业示例，与本人无关。
